## ToneMix トーンミックス 技術説明書

### 1. ToneMixについて
このアプリケーションは、複数の周波数を同時に生成し、個別に音量調整が可能なトーンジェネレーターです。「ToneMix」という名称で、Progressive Web App（PWA）として動作するように設計されています。

**主な機能:**
* 複数の異なる周波数の音を同時に再生
* 各周波数に対する独立した音量調整
* Webブラウザからの直接アクセス
* PWAとしてのインストールとオフライン動作のサポート

### 2. 使い方 (概要)
* Webブラウザでアプリケーションにアクセスします。
* モバイルデバイスではPWAとしてホーム画面に追加し、ネイティブアプリのように利用できます。
* インターフェース上で周波数を追加し、スライダーで音量を調整して再生します。

### 3. 技術情報

#### 3.1. ファイル構成
`/home/stand/tone-generator`ディレクトリの構成は以下の通りです。

```
/home/stand/tone-generator/
├── index.html
├── manifest.webmanifest
├── sw.js
└── icons/
    ├── icon-maskable-512.png
    ├── apple-touch-icon-180.png
    ├── icon-192.png
    └── icon-512.png
```

#### 3.2. 各ファイルの役割
* **`index.html`**: アプリケーションのメインエントリポイントとなるHTMLファイルです。ページの構造（ヘッダー、音量コントロールなどのUI要素）、基本的なスタイル（CSS）、およびJavaScriptのロードを定義しています。`title`メタタグに「ToneMix トーンミックス」とあり、`description`には「複数の周波数を同時に鳴らせるトーンジェネレーター。音量は音ごとに調整OK。」と記載されています。Web Audio APIを使用して音を生成・制御するJavaScriptコードが含まれていると推測されます。PWA関連のメタタグ（`manifest.webmanifest`へのリンク、`apple-touch-icon`の指定など) も含まれています。
* **`manifest.webmanifest`**: PWAの設定ファイルです。アプリケーションの名称、ショートネーム、アイコンのパス、表示モード、テーマカラー、背景色などが定義されており、PWAとしてインストールされる際の挙動や表示を制御します。
* **`sw.js`**: Service Workerのスクリプトファイルです。オフラインサポート、プッシュ通知、バックグラウンド同期などのPWA機能を提供するために使用されます。アプリケーションのリソースのキャッシュ戦略が実装されていると推測され、オフライン時でもアプリケーションが利用可能になります。
* **`icons/`ディレクトリ**: アプリケーションで使用される各種サイズのアイコン画像が含まれています。PWAのインストール時やホーム画面に表示されるアイコン、ファビコンなどに利用されます。`icon-192.png`、`icon-512.png`、`icon-maskable-512.png`、`apple-touch-icon-180.png`など、様々なデバイスやプラットフォームに対応したアイコンが用意されています。
